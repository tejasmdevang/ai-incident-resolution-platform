# AI Incident Resolution Platform

A production-oriented platform for collecting operational evidence and assisting engineers with incident investigation and root-cause analysis.

## Current Status

Project setup and backend foundation are in progress.

## Planned Capabilities

- Incident lifecycle management
- Operational evidence collection
- Log and metric correlation
- Deployment-history analysis
- AI-assisted root-cause analysis
- Recommended remediation actions
- Investigation timeline and audit history

## Technology Stack

- Java 17
- Spring Boot
- PostgreSQL
- Maven
- Flyway
- React
- Python AI service
- Docker

## Project Motivation

Production incident investigation often requires engineers to move between logs, metrics, deployment history, source-code changes, and ticketing systems. This project explores how those sources can be brought together into a structured investigation workflow.

## Development Status

The project is being built incrementally. Features and documentation will be updated as each milestone is completed.
